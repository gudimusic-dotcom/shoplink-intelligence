# SHOPLINK Intelligence

Ez a mappa a SHOPLINK Intelligence projekt hivatalos Codex munkaterülete.

## Első olvasandó fájlok minden workstationön

Folytatás előtt mindig ezt a 3 fájlt kell megnyitni ebben a sorrendben:

1. `docs/WORKSTATE.md`
2. `docs/SESSION_LOG.md`
3. `docs/RESUME_PROTOCOL.md`
